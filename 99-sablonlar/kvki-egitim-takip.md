# KVKK Eğitim Takip Formları

## 1. Eğitim Programı Yapısı

| Eğitim Tipi | Hedef Grup | Süre | Sıklık |
|-------------|-----------|------|--------|
| Temel KVKK Farkındalık | Tüm çalışanlar | 60-90 dk | İşe başlangıç + yıllık |
| Genişletilmiş KVKK | Yöneticiler | 4 saat | Atama + yıllık |
| İK KVKK Uygulamaları | İK personeli | 4 saat | Atama + yıllık |
| BT/Geliştirici KVKK | Geliştirici, sistem yöneticisi, DBA | 4 saat | Atama + yıllık |
| Çağrı Merkezi KVKK | Çağrı merkezi personeli | 2 saat | Atama + 6 aylık |
| Pazarlama KVKK | Pazarlama, dijital, CRM | 3 saat | Atama + yıllık |
| Hukuk-İhlal Müdahale | KVKK ekibi, hukuk, BT | 6 saat (tatbikat) | Yıllık |
| Tedarikçi Yönetimi KVKK | Tedarik, satınalma | 2 saat | Atama + yıllık |
| Phishing Simülasyon | Tüm çalışanlar | 5 dk | Çeyreklik |

## 2. Müfredat Kontrol Listesi

### 2.1 Temel KVKK Farkındalık (Asgari İçerik)

- [ ] KVKK'nın amacı, kapsamı, temel kavramlar
- [ ] Kişisel veri ve özel nitelikli veri ayrımı
- [ ] Veri sorumlusu ve veri işleyen
- [ ] İşleme şartları (m.5, m.6) — açık rıza vs. diğer hukuki sebepler
- [ ] Aydınlatma yükümlülüğü
- [ ] İlgili kişi hakları (m.11)
- [ ] Veri güvenliği — temel sorumluluklar
- [ ] İhlal tespit ve bildirim — 24 saat iç bildirim
- [ ] Yaptırımlar — idari para cezası, suç tipleri
- [ ] Şirketin politikaları — özet
- [ ] Bilgi testi (≥%80 başarı)
- [ ] Sorumluluk taahhüdü

### 2.2 Yöneticiler için Genişletilmiş

- [ ] Temel müfredat içeriği +
- [ ] Yönetici sorumlulukları (örnek olma)
- [ ] Kararı destekleme — sistem yatırımı, eğitim
- [ ] Tedarikçi sözleşme onayında KVKK kontrolü
- [ ] Birim seviyesinde envanter güncel tutma
- [ ] İhlal müdahale — yönetici rolü
- [ ] Çalışan farkındalığı izleme
- [ ] KPI okuma ve takip

### 2.3 İK için Uygulamalı

- [ ] Aday CV saklama süreleri ve imha
- [ ] Özlük dosyası KVKK uyumu
- [ ] Sağlık verisi işleme — özel önlemler
- [ ] Performans değerlendirme — KVKK boyutu
- [ ] CCTV ve PDKS — meşru menfaat değerlendirmesi
- [ ] İş akdi feshi sonrası veri yönetimi
- [ ] Eğitim, etkinlik, fotoğraf paylaşımı
- [ ] Ücret bilgisi gizliliği
- [ ] Disiplin süreçleri ve KVKK

### 2.4 BT / Geliştirici için Teknik

- [ ] Privacy by Design — geliştirme yaşam döngüsünde
- [ ] Veri minimizasyonu — kod uygulaması
- [ ] Şifreleme standartları (rest+transit)
- [ ] Erişim yönetimi, RBAC, MFA
- [ ] Loglama — kişisel veri içermeyen log mantığı
- [ ] Yedekleme ve imha — yedeklerden veri silme
- [ ] Test ortamlarında veri — anonimleştirme ve maskeleme
- [ ] Üçüncü taraf entegrasyonu — DPA kontrolü
- [ ] Bulut güvenliği — paylaşılan sorumluluk
- [ ] Açık kaynak ve lisans
- [ ] Sızma testi sonuçlarına aksiyon
- [ ] Olay müdahale teknik adımları

### 2.5 Çağrı Merkezi için

- [ ] Aydınlatma metni doğru okuma / SMS gönderimi
- [ ] Müşteri kimlik doğrulama
- [ ] Açık rıza alma süreçleri
- [ ] Müşteri talebine doğrudan cevap vermeme — yönlendirme
- [ ] Başvuru kayıt ve KVKK ekibine iletme
- [ ] Ses kaydı ve gizlilik
- [ ] Müşteri verisi paylaşmama
- [ ] Sosyal mühendislik tehditleri

### 2.6 Pazarlama için

- [ ] Açık rıza vs. meşru menfaat ayrımı
- [ ] Ticari elektronik ileti rejimi (İYS)
- [ ] Profilleme ve otomatik karar — m.11/g
- [ ] Çerez Rehberi uyumu
- [ ] Üçüncü taraf etiket yöneticisi rıza koşullandırma
- [ ] Pazarlama veritabanı temizliği
- [ ] CRM ve segmentasyon
- [ ] Kampanya sonrası imha

## 4. LMS / Online Eğitim Takip

LMS (Learning Management System) kullanılıyorsa aşağıdaki minimum alanlar:

| Alan | Açıklama |
|------|----------|
| Kullanıcı ID | Çalışan sicil no veya e-posta |
| Eğitim modülü ID | Müfredat kodu |
| Atama tarihi | Çalışana atanma |
| Tamamlanma tarihi | Tamamlanma kaydı |
| Geçirilen süre | Min. süre eşik kontrolü |
| Test sonucu | %80 eşik |
| Sertifika no | Otomatik üretim |
| Sürüm | Eğitim materyali sürüm |
| Onay (yönetici) | Gerekirse onay akışı |

## 5. Yıllık Müfredat Gözden Geçirme

| Adım | Sahip | Termin |
|------|-------|--------|
| Mevzuat değişiklik etkilerinin müfredata yansıtılması | KVKK Sor. + Hukuk | Aralık |
| Önceki yıl ihlal/şikâyet konularının müfredata eklenmesi | KVKK Sor. | Aralık |
| Yeni roller için modül tasarımı | İK + KVKK Sor. | Aralık |
| Yıllık eğitim takvimi | KVKK Sor. + İK | Ocak |
| Müfredat onayı | KVKK Komitesi | Ocak |

## 7. Eğitim KPI'ları (Aylık)

| KPI | Hedef | Veri Kaynağı |
|-----|-------|---------------|
| Genel eğitim tamamlama oranı | ≥%95 | LMS |
| Kritik rol tamamlama oranı | %100 | LMS |
| Bilgi testi başarı oranı | ≥%90 | LMS |
| Phishing tıklama oranı | ≤%5 | Phishing platformu |
| Eğitim memnuniyet skoru | ≥4.0/5 | Anket |

## 8. Eğitim Kayıt Saklama

- LMS kayıtları: çalışan iş ilişkisi sona erdikten sonra 5 yıl
- Sertifikalar: çalışanın özlük dosyasında 10 yıl
- Eğitim materyalleri (sürüm bazlı): süresiz arşiv (denetim hazırlığı)
- Phishing kampanya raporları: 5 yıl
