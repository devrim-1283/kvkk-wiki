# Meşru Menfaat Değerlendirmesi (LIA)

> **AMAÇ:** KVKK m.5/2-(f) bendi kapsamında "ilgili kişinin temel hak ve özgürlüklerine zarar vermemek kaydıyla, veri sorumlusunun meşru menfaatleri için veri işlemenin zorunlu olması" hukuki sebebine dayanılması durumunda, denge testinin yapıldığını belgelemek için kullanılır.

> **NE ZAMAN GEREKLİ:** m.5/2-(a, b, c, ç, d, e) bentlerinden biri uygulanamıyorsa ve açık rıza yerine meşru menfaate başvuruluyorsa, bu form **zorunludur**.

> **BELGELEME:** LIA tamamlandıktan sonra ilgili süreç envanterinde "hukuki sebep: m.5/2-(f) — LIA dosyası: [REF]" şeklinde kaydedilir.

## Pratik Notlar

### Tipik Meşru Menfaat Senaryoları

| Senaryo | Genelde Geçer mi? |
|---------|-------------------|
| Site güvenliği için IP/log toplama | Evet (orantılı) |
| Dolandırıcılık önleme | Evet (orantılı) |
| Hizmet kalitesinin ölçülmesi (anonim/pseudonymize) | Evet |
| İçeride yöneticiye çalışan performansı raporu | Evet (sınırlı, şeffaf) |
| Pazarlama için davranış izleme (rıza yok) | Genelde **Geçmez** — açık rıza tercih |
| Üçüncü tarafa pazarlama amaçlı veri satışı | **Geçmez** — açık rıza zorunlu |
| Çalışan e-posta sürekli izleme | Genelde **Geçmez** veya sınırlı kapsamla |
| Mevcut müşteriye benzer ürün önerisi (e-ticaret) | Sınırlı, opt-out ile geçebilir |
| CCTV (mağaza/ofis güvenliği) | Genelde geçer (orantılı, tabela ile) |
| Kalabalık alanda biyometrik tarama | **Geçmez** — özel nitelikli, m.6 ayrı |

### Hata Yapılan Yerler

- "Meşru menfaat" battaniyesi olarak kullanma (her zaman geçer mantığı yanlıştır)
- Denge testini sadece veri sorumlusu lehine yapma
- İlgili kişiye opt-out hakkı sunmama
- LIA dokümante etmeme
- Yıllık tazelememe

### KVKK m.11/g — Otomatik Karar İtirazı

Meşru menfaate dayanan profilleme veya otomatik karar süreçlerinde, ilgili kişi m.11/1-(g) bendi uyarınca **aleyhe sonuca itiraz** edebilir. LIA dosyasında bu hak için süreç tanımlanmalıdır.
