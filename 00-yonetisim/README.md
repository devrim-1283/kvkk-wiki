# 00 — Yönetişim

## Bölümün Amacı

Bu bölüm, KVKK uyum programının **kurumsal yönetişim** katmanını oluşturur. Mevzuat yükümlülüklerinin operasyonel düzeyde sahiplenilmesi, çapraz fonksiyonel kararların alınması, hesap verebilirliğin tesisi ve yıllık döngünün yönetimi bu bölümdeki dokümanlar üzerinden yapılır.

KVKK m.12 kapsamındaki **idari tedbirler** yükümlülüğünün somut karşılığı bu bölümdür: rol-sorumluluk tanımlaması, yönetişim organlarının kurulması, yönetim kurulu raporlama hattı, yıllık takvim ve hesap verebilirlik matrisi.

## Kullanım Sırası

Bu bölümdeki dokümanlar bağımsız okunabilir, ancak yeni kuruluş aşamasında aşağıdaki sıra önerilir:

1. **kvkk-sorumlusu-rolu.md** — Kim sahiplenecek?
2. **irtibat-kisisi.md** — Kurum'la iletişim kim sağlayacak?
3. **komite-yapisi.md** — Çapraz fonksiyonel karar mekanizması nasıl işleyecek?
4. **raci-matrisi.md** — Spesifik aktivitelerde rol-sorumluluk netleşsin
5. **yillik-takvim.md** — Yıllık ritim oturduktan sonra konsolidasyon
